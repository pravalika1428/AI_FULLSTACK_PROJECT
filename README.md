# College FAQ Chatbot

A simple AI-powered College FAQ Chatbot built using Python, Streamlit, Ollama, and ChromaDB.

## Features

- Answers common college-related questions
- Uses semantic search
- Uses ChromaDB for storing FAQ embeddings
- Uses Ollama for local AI responses
- Simple Streamlit web interface

## Technologies Used

- Python
- Streamlit
- Ollama
- ChromaDB
- Sentence Transformers
- Llama 3.2
- Nomic Embed Text
